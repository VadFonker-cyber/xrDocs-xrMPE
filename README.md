# xrDocs

Статический сайт для Markdown-документации по моддингу S.T.A.L.K.E.R. Работает локально через Vite и публикуется на GitHub Pages без backend.

## Локальный запуск

Двойной клик по файлу:

```text
dev.bat
```

Или запуск из терминала:

```powershell
npm.cmd install
npm.cmd run dev
```

После запуска Vite откроет сайт в браузере автоматически. Обычно это `http://127.0.0.1:5173/`.

В PowerShell на этой машине `npm` может блокироваться политикой выполнения скриптов, поэтому используйте `npm.cmd`.

## Сборка

```powershell
npm.cmd run build
```

Готовые файлы появятся в `dist/`.

## Markdown-страницы и языки

Материалы лежат отдельно по языкам:

- `docs/ru/**/*.md` для русской версии
- `docs/en/**/*.md` для английской версии
- `docs/ru/init.md` и `docs/en/init.md` задают порядок меню и сами не отображаются как статьи

URL строится как `#/ru/index` или `#/en/index`. Если в обоих языках есть файл с одинаковым относительным путем, например `docs/ru/addon-structure.md` и `docs/en/addon-structure.md`, переключатель RU/EN откроет соответствующую страницу на другом языке.

Порядок страниц задается в `init.md` в стиле mdBook:

```md
# Основы

- [Быстрый старт](index.md)
- [Структура аддона](addon-structure.md)

# Конфиги

- [LTX-конфиги](configs-ltx.md)
```

Заголовки становятся разделами в меню. Пункты списка задают порядок файлов. Если файл не указан в `init.md`, он все равно попадет в меню после явно отсортированных страниц.

Для страницы используйте frontmatter:

```md
---
title: Название страницы
section: Раздел
order: 10
tags: weapons, configs
summary: Короткое описание для меню.
---

# Название страницы
```

Ссылки на другие `.md` файлы автоматически превращаются во внутренние переходы сайта.

## Поиск

Поиск работает по текущему языку и ищет совпадения в:

- названии страницы
- разделе
- тегах
- summary
- содержимом Markdown
