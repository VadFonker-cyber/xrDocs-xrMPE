# Структура аддона

Типичный аддон хранит измененные ресурсы в `gamedata`. Держите структуру близкой к оригинальной раскладке игры: так файлы проще сравнивать, отключать и отлаживать.

## Минимальная раскладка

```text
gamedata/
  configs/
  scripts/
  meshes/
  textures/
  sounds/
```

## Практика

- Разделяйте изменения по подсистемам: оружие, NPC, квесты, интерфейс.
- Держите временные тесты отдельно от релизных файлов.
- Добавляйте короткую заметку к конфликтующим конфигам, объясняющую причину изменения.

> Чем меньше скрытых зависимостей между файлами, тем проще поддерживать сборку мода.
