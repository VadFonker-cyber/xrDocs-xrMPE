# LTX-конфиги

LTX-файлы описывают множество игровых сущностей: оружие, предметы, секции NPC, погоду и экономику. Для моддинга важно сохранять изменения читаемыми.

## Рекомендации

- Меняйте одну группу параметров за раз и проверяйте результат в игре.
- Держите исходное значение рядом, если балансный параметр часто пересматривается.
- Группируйте связанные секции в одном документе базы знаний.

```ini
[wpn_example]:identity_immunities
hit_power = 0.42
fire_distance = 600
control_inertion_factor = 1.2
```

## Что документировать

Фиксируйте назначение секции, ключевые параметры, риски совместимости и игровые сценарии, где изменение должно быть заметно.
