# Быстрый старт

Этот сайт собирает Markdown-файлы из папки `docs/ru` для русской версии и `docs/en` для английской версии.

## Как добавить страницу

1. Создайте новый файл, например `docs/ru/weapons/ballistics.md`.
2. Добавьте frontmatter в начало файла.
3. Напишите материал обычным Markdown.

```md
---
section: Оружие
order: 10
summary: Параметры точности, отдачи и урона.
---

# Баллистика оружия
```

После сборки документ появится в меню текущего языка. Внутренние ссылки на `.md` файлы преобразуются в hash-маршруты, например [структура аддона](addon-structure.md).

## GitHub Pages

Сайт не требует backend. Команда `npm.cmd run build` создает папку `dist/`, которую можно публиковать через GitHub Pages.
