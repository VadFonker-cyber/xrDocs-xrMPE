# Поддержка

[English](../.github/SUPPORT.md)

Используйте GitHub Issues для:

- сообщений об ошибках;
- неточной или отсутствующей документации;
- предложений новых разделов;
- проблем со сборкой или публикацией.

Перед созданием Issue проверьте существующие Issues и Pull Requests. Если проблема связана со страницей, укажите язык (`ru` или `en`), путь страницы, браузер и шаги воспроизведения.
