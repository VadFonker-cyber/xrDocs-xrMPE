# Политика безопасности

[English](../.github/SECURITY.md)

## Поддерживаемые версии

Проект является статическим сайтом документации. Исправления безопасности вносятся в текущую ветку `main`.

## Как сообщить об уязвимости

Не публикуйте чувствительные детали безопасности в публичном Issue.

Если в репозитории включены private vulnerability reports GitHub, используйте их. Иначе свяжитесь с владельцем репозитория приватно и укажите:

- затронутые файлы или workflow;
- шаги воспроизведения;
- ожидаемое влияние;
- возможное исправление, если оно известно.

Для проблем с зависимостями укажите имя пакета, затронутую версию, ссылку на advisory и результат `npm audit`, если он доступен.
